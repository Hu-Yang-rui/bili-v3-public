- **空降助手：跳过区间直接画在进度条上** —— 拖动前就能看见哪几段会被自动跳过，按类别分色（恰饭广告 / 三连提示 / 片头片尾 / 其它），不再只在跳过的一瞬间闪一条提示
- **投币改成女仆装小人** —— 抬手 → 从空中取下浮空硬币 → 拿住 → 投向画面，硬币带浮空光效、能量波纹与粒子；拿着的硬币数量跟着选择实时变
- **投币数量支持点击 + 左右滑动** —— 两种操作指向同一份状态，不会出现「高亮 1 枚却投了 2 枚」
- **直播改为应用内播放**（不再跳系统浏览器）—— 支持 HLS 直播流；未开播时显示空态与刷新按钮，而不是一片黑屏；新增「隐身入场」开关（开启后进入直播间不发送入场上报）
- **新增 AI 总结** —— 优先取 B 站官方总结，取不到再用你自己配置的 OpenAI 兼容模型（基于视频现有字幕生成）；API 地址 / 模型 / Key 都可自定义，Key 走 Android Keystore 加密保存，页面上只显示脱敏摘要
- **新增「特别关注」** —— 纯本地书签，**不会**关注对方的 B 站账号，不影响粉丝数，也不向 B 站发送任何关注请求

**已知限制（如实说明）**

- 直播播放**尚未在真机上验证**（开发机无设备）：取流接口与 HLS 清单已实测可用，但「画面真的出来」需要装机确认
- AI 总结的**官方分支需要登录态**：未登录时官方接口返回 `-403`，会自动降级到你配置的第三方 AI；若两者都不可用，会明确提示缺哪一项
- 直播**不做弹幕**（需要 WebSocket 长连接，与视频弹幕是两套机制）

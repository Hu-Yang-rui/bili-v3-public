> ⚠️ **这是测试版（Pre-release），不是正式版。**
>
> **它比正式版 `v1.6.8` 多了下面这些改动** —— 两者代码**不同**，
> 只是 `versionName` 都是 `1.6.8`（因为没升版本号，所以装机后看不出来）。
>
> 正式版 `v1.6.8` 不受影响，别人点进 Releases 默认下到的仍是它。

- **整个 App 换成浅色主题** —— 之前是纯黑底。这一版把全部界面改为白底浅色：页面底、分组底、文字、品牌色、状态色、骨架屏、占位图全部按白底重新配过对比度（正文 21:1、次要文字 4.5:1、链接 5.6:1）。播放器画面、弹幕、字幕这些压在视频上的部分仍然是深色 —— 它们要保证白字在画面上可读，与主题无关
- **修好「浅色下分组线全部消失」** —— 这是一个只在浅色下才暴露的问题：分组用的发丝线原本写死是**白色 10%**，白线画在白底上完全看不见。实测顶栏下方那条线的对比度是 **1.00:1**（等于没有）。全项目 **62 处、34 个文件**的分组边界一次性失效。现在线会跟随主题：深色下是白线，浅色下是黑线
- **修好「浅色下底栏浮层消失」** —— 底栏是悬浮玻璃胶囊，但浅色下"玻璃糊白色"的结果**还是白色**，实测它与页面底的对比度只有 **1.11:1**，和白色内容区糊成一片，看不出那是个浮层。现在浅色下改用**边缘环 + 投影**来分层（深色下靠底色差，那条路在浅色下不存在）
- **修好竖屏模式「进得去出不来」** —— 竖屏页的返回按钮原本只写在「有内容」的分支里，于是**加载中 / 加载失败 / 没有竖屏内容**这三种状态下整屏没有任何返回入口。实测：探测失败时屏幕上只有「重试」，而「重试」在探测持续失败时同样无效，**形成死循环**。现在返回按钮无条件存在
- **搜索结果改为两列网格** —— 之前搜索结果是一列全宽大卡，而首页是两列。同一支视频在首页是两列小卡、搜出来变成全宽大卡。现在与首页同源（平板三列、桌面四列自动适配）
- **空状态回到页面视觉中心** —— 「还没有缓存任何视频」这类空态之前**贴在左下角**（垂直方向其实居中，但水平方向贴左）。这个组件被 12 个页面复用，一处修复全部生效
- **番剧详情页两处调整** —— ①「追番」按钮之前缩在封面右侧（宽度被封面挤掉），现在是整行宽的主操作；②选集格子之前每个都铺一块灰底，八集排下来是一屏灰色方块，现在去掉底色、靠间距分组
- **去掉 336 个失效引用** —— 纯内部清理，无用户可见变化

**已知限制（如实说明）**

- **浅色主题只做了主要页面的实机核对**：首页 / 搜索 / 动态 / 我的 / 设置 / 视频详情 / 番剧 / 历史 / 收藏 / 离线缓存 / 插件中心 / 播放队列 / 特别关注 / 切换账号 已逐页截图确认。**直播 / 私信 / 排行榜 / 分区 / 竖屏 / 沉浸播放器 / 登录页 / 番剧详情** 未逐页核对（代码层已审计，但没看实际效果）
- **各弹层（Sheet / Dialog / 菜单）在浅色下的表现未逐一核对**
- **卡片堆砌 / 间距 / 字体 / 图标的全局一致性检查尚未做完**
- **折射效果未在真机验证**：本机只有模拟器，是软件渲染（SwiftShader），与真机 GPU 表现不同
- **手机上没有进入「直播」的入口**：顶栏的「直播」链接和侧栏的「正在直播」都只在平板/桌面显示。这是**既有问题**（不是本次改动造成的），但如实写出。对比：番剧有移动端兜底（点分区里的「番剧」进番剧索引），直播缺同样的兜底
- **测试版的改动说明可能滞后**：如果我在推完这个 beta 之后又改了代码，那些改动不在这里

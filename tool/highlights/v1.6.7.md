- **界面全面重做** —— 重建了整套视觉体系：三层语义色（区域 / 控件 / 文字各司其职）、11 档语义排版、8pt 网格、按组件分配的圆角、spring 动效。主色从「粉色」改为「交互蓝」，粉色回归品牌标识 —— 此前每个可点元素都是粉的，等于什么都不强调
- **底部导航改为悬浮玻璃胶囊** —— 四边离屏、选中指示器会随移动速度弹性形变；内容从它下面滚过
- **液态玻璃有真折射了** —— 玻璃边缘会像透镜一样把背后内容轻微"掰弯"，并带一点色散。压在画面上时取画面的模糊副本，与画面融合，而不是盖一块灰板
- **首页顶栏与内容重排** —— 搜索框改为填充胶囊（此前是一条几乎看不见的底线）；视频封面恢复圆角；元信息改为「UP 名 · 播放量」一行
- **视频详情页结构重排** —— 顺序改为「标题 → 数据 → UP → 互动」。此前是「头像 → 名字 → 粉丝数 → 标题」，即先看到"谁发的"才看到"是什么视频"
- **设置页去掉章节序号** —— 从 `01 ── 播放` 改为无序号标签（序号需要手工维护，此前已因此出过两次重复编号的问题）
- **新增「自动画质 / 音质」设置** —— 可配置首选 / 备选画质、优先杜比全景声、优先 Hi-Res 无损、直播画质开关，以及 8K / 杜比视界 / AV1 的请求开关。默认全部关闭，不影响原有行为
- **默认清晰度设置项真正生效了** —— 此前设置页能选，但没有任何代码读它（是个死入口）

**已知限制（如实说明）**

- **界面重做只完成了一部分页面**：首页、视频详情、播放器控制层、设置页已按新设计重构；**搜索 / 动态 / 用户主页 / 收藏 / 私信 / 直播 / 番剧 / 排行榜 / 分区页 / 插件中心 / 离线缓存 / 账号页**仍是旧布局（颜色已随新调色板切换，但布局与组件还是旧的）。所以整体观感会**新旧混杂** —— 这是未完成状态，不是最终形态
- **折射效果没有在真机上验证**：本机只有模拟器，而模拟器是**软件渲染**（SwiftShader），与真机 GPU 表现不同。观感与性能都需要真机确认
- **杜比全景声 / Hi-Res 无损不能主动请求**：它们的请求位实测会让整条取流请求返回 `-400 请求错误` —— 不是"没有提升"，而是**视频都放不了**。所以那两项只做「服务端给了就用」，不做「主动索要」
- **会员账号下的音轨未验证**：本机非大会员（实测 `dash.dolby.type` 恒为 0、`dash.flac` 恒为 null），所以"会员能否真的拿到杜比 / 无损"**没有验证过**
- **首选 → 备选画质的回退路径未在真实多档视频上走通**：当前账号可用档位只有 360P / 480P，只验证了逻辑（有单测覆盖）
- **「解锁设置」只是请求参数，不是破解**：非会员账号带上这些参数，服务端**照样只给 480P**（本项目已实测）。能不能拿到由账号权限决定，不是由开关决定
- **APK 体积变大**：release 从 3.6 MB 增至 **3.92 MB**（液态玻璃库的体积）
